# Code of conduct

## Our standard

Be respectful. This project is a small maintainer toolkit; contributors and users should be able to report bugs, ask questions, and review patches without harassment, personal attacks, or spam.

## Unacceptable behavior

- Insults, slurs, or targeted harassment
- Publishing private information
- Sexualized language or imagery
- Repeated off-topic promotion

## Enforcement

Report incidents to the maintainers via GitHub security advisory or a private email listed on the maintainer profile. Maintainers may warn, hide comments, or block people who break this standard.

This code of conduct applies to repositories, issues, pull requests, and any official community space for oss-steward.
